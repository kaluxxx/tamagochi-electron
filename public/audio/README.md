# Assets Audio

Ce dossier contient les fichiers audio pour la musique de fond et les effets sonores.

## Structure

```
audio/
├── music/           # Musiques de fond (loop)
│   ├── main-theme.mp3
│   ├── shop-theme.mp3
│   ├── clicker-theme.mp3
│   ├── fishing-theme.mp3
│   └── minigames-hub.mp3
└── sfx/             # Effets sonores
    ├── click.mp3
    ├── purchase-success.mp3
    ├── purchase-fail.mp3
```

## Sources Recommandées (Libres de droits)

### Musique 8-bit/Chiptune

1. **HydroGene sur itch.io** (CC0 - Gratuit)
   - https://hydrogene.itch.io/high-quality-8-bit-musics
   - 18 tracks 8-bit parfaits pour jeux

2. **OpenGameArt.org** (CC0/CC-BY)
   - https://opengameart.org/art-search-advanced?keys=chiptune
   - Grande collection de musiques gratuites

3. **Soundimage.org** (Royalty-Free)
   - https://soundimage.org/chiptunes/
   - Tracks chiptune téléchargeables en MP3

4. **Patrick de Arteaga** (Royalty-Free)
   - https://patrickdearteaga.com/en/chiptune-8-bit-retro/
   - Musiques 8-bit non-copyrightées

### Effets Sonores

1. **Freesound.org** (CC0/CC-BY)
   - https://freesound.org/search/?q=8bit
   - SFX 8-bit communautaires

2. **OpenGameArt.org** (CC0)
   - https://opengameart.org/art-search-advanced?keys=8bit+sfx
   - Packs de sons retro

## Recommandations par Track

| Fichier | Style recommandé |
|---------|-----------------|
| main-theme.mp3 | Calme, joyeux, ~80 BPM |
| shop-theme.mp3 | Upbeat, jazzy, ~100 BPM |
| clicker-theme.mp3 | Énergique, rapide, ~140 BPM |
| fishing-theme.mp3 | Relaxant, ambient, ~60 BPM |
| minigames-hub.mp3 | Arcade, fun, ~120 BPM |

## Format

- **Format**: MP3 (compatible tous navigateurs)
- **Durée musique**: 1-3 minutes (loop seamless)
- **Durée SFX**: < 2 secondes
- **Qualité**: 128-192 kbps suffisant
